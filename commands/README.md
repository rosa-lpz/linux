# Linux Commands

## Permissions

Manage file permissions and ownership.

| Command                           | Description        |
| --------------------------------- | ------------------ |
| [`chmod`](permissions/chmod.md)   | Change permissions |
| `chmod 755 file`                  | Set rwxr-xr-x      |
| `chmod +x file`                   | Add execute        |
| [`chown`](permissions/chown.md)   | Change owner       |
| [`chgrp`](permissions/chgrp.md)   | Change group       |
| [`chattr`](permissions/chattr.md) | Change attributes  |
| [`umask`](permissions/umask.md)   | Set default perms  |
